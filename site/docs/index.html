Weft is a folder of plain HTML files you own, with a daemon that surfaces and (optionally) syncs them. Start here.

Start

Getting started
Install Weft, point it at a folder, and start writing. One binary, a local daemon, a vault of plain .html files, and a brain panel that surfaces what matters.

Concepts

Concepts
How Weft thinks: HTML files you own, surfacing over searching, and an ACT-R memory-activation model that ranks what your brain would recall right now.

Sync

Sync
Bring-your-own-cloud, end-to-end encrypted sync for your Weft vault. The vault key never leaves your device; the cloud holds only ciphertext.

Devices
Add a device with weft sync pair (no passphrase), compare the 8-digit SAS, and confirm. Plus keychain caching and 24-word recovery.

Reference

MCP
Run weft mcp to expose your vault to Claude Code over stdio — read, search, surface, and write notes from inside Claude Code.

Import
Bring existing notes into your Weft vault from markdown, Notion, browser bookmarks, or Apple Notes. Imported notes become plain .html files.

CLI
Every Weft command and its flags, verbatim: serve, capture, clip, mcp, import, and the full sync subcommands — plus keychain and recovery-phrase environment notes.
